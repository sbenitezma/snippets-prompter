# Snippets Prompter — backend (optional phase 2)

A bare NestJS scaffold, kept as the starting point for the optional backend
phase. The app's primary scope is frontend-only and does not use it; see
[ADR 0003](../docs/adr/0003-scope-pivot-frontend-only.md) for the decision and
[ADR 0001](../docs/adr/0001-backend-framework.md) for why NestJS.

```bash
npm install
npm run start:dev   # development server with watch mode
npm test            # unit tests (Vitest)
npm run test:e2e    # end-to-end tests
```
